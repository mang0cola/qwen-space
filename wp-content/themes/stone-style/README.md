# Stone & Style - WordPress Theme

A luxury stone curator platform WordPress theme with WebGL-powered visual storytelling.

## Project Overview

**Stone & Style** is a premium WordPress theme for showcasing high-end surface materials and stone products. The theme features:

- **WebGL + Custom Shaders** - Voronoi noise transitions, mouse-follow glow effects
- **GSAP Animations** - Scroll-triggered animations with ScrollTrigger plugin
- **Barba.js** - SPA-like page transitions without refresh
- **Custom Cursor** - Six-state interactive cursor system
- **Data-driven Spacing** - Viewport-based spacing system (`spr`, `spr-s`)
- **Multi-language** - English/Thai support via WPGlobus
- **Dark/Light Mode** - JS-driven theme switching

## Tech Stack

### Backend
- WordPress (Custom Theme)
- PHP 7.4+
- Nginx with HTTP/2, HTTP3

### Frontend
- THREE.js r132+ (WebGL)
- GSAP 3 + ScrollTrigger
- Barba.js 2.x
- WebFont Loader
- Webpack 5

## Installation

### Prerequisites
- Node.js 16+
- npm or yarn
- WordPress 5.8+
- Composer (optional)

### 1. Install Dependencies

```bash
cd wp-content/themes/stone-style
npm install
```

### 2. Build Assets

**Development:**
```bash
npm run dev
```

**Production:**
```bash
npm run build
```

### 3. Activate Theme

1. Upload the `stone-style` folder to `/wp-content/themes/`
2. Activate via WordPress Admin → Appearance → Themes
3. Configure menus under Appearance → Menus

## Features

### Custom Post Types
- **Brands** - Surface material brands (Antolini, Silestone, etc.)
- **Gallery Items** - Project showcase items

### Page Templates
- `page-home.php` - Homepage with full-width sections
- `page-brands.php` - Brands listing
- `page-gallery.php` - Portfolio gallery
- `page-contact.php` - Contact form

### Spacing System

Desktop (5vh multiplier):
```html
<div class="spr" data-n="2"></div>  <!-- 10vh -->
<div class="spr" data-n="3.5"></div> <!-- 17.5vh -->
```

Compact (6vh multiplier):
```html
<div class="spr-s" data-n="3"></div> <!-- 18vh -->
```

### Responsive Breakpoints
- Desktop: > 1024px
- Tablet: 641-1024px  
- Mobile: ≤ 640px

## Customization

### Colors

Edit `src/scss/base/_variables.scss`:
```scss
:root {
    --c-white: #fcfcfc;
    --c-black: #050505;
    --c-gray-a: #8d8d8d;
}
```

### Fonts

The theme uses:
- **Felix** - Custom serif (place woff2/woff in `assets/fonts/`)
- **nimbus-sans** - Adobe Fonts (configure Typekit ID)
- **Sarabun** - Google Fonts (Thai language)

## Performance

- Image lazy loading
- Draco-compressed GLTF models
- Critical CSS inlined
- JS bundled with defer
